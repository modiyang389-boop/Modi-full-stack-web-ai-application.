Version control is a tool that tracks your work as you make changes. It acts like an undo button for your project, letting you go back to an earlier step if you make a mistake. Instead of making lots of extra copies of your files, it saves your progress automatically and helps people work together without messing up each other's work. Most people use two tools called Git and GitHub. Git is a program on your computer that saves quick snapshots of your work, while GitHub is a website where you back up those snapshots. A project folder is called a repository, a saved snapshot is a commit, uploading is a push, and downloading is a pull. using git and GitHub makes  sharing and working with others becomes very easy.
